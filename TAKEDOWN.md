# Takedown Request

SnapBench query and gallery images are collected from publicly accessible web sources, then filtered for copyright, safety, and research use. We do not release the original private image pool.

If you are a rights holder and believe an image should not appear in this research release, email both contacts below with:

1. Your name and a way to verify you represent the rights holder
2. A direct link to the image in this repository or on Hugging Face
3. The local filename if you have it (for example `bench_images/query/0000.jpg` or `08805.jpg`)
4. A short description of the claim

We will review the request and, if the claim is valid, remove the image from subsequent releases of the GitHub and Hugging Face copies.

Please put `[SnapBench takedown]` in the subject line.
